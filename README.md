# 🔀 GitHub Clone Project

A Git branching exercise from the **ALX Software Engineering** programme: clone a repository, work on a feature branch and merge changes back into `main`.

![Git](https://img.shields.io/badge/Git-F05032?style=flat-square&logo=git&logoColor=white)

## What I practised

- `git clone` to copy a repository from GitHub
- Creating and switching branches (`git checkout -b feature-greeting`)
- Committing on separate branches ([`greetings.txt`](greetings.txt), [`feature.txt`](feature.txt))
- Merging a feature branch into `main` and resolving conflicts
- Pushing branches with `git push -u origin <branch>`
